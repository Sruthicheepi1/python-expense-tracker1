# Python Expense Tracker

## Project Description

This project is a basic Python Expense Tracker application.
It allows users to add expenses, view expenses, calculate
total expenses, and save expenses to a text file.

## Features

- Add expenses
- View expenses
- Calculate total expenses
- Save expenses to a file

## Technologies Used

- Python

## Concepts Used

- Variables
- Lists
- Loops
- Conditional statements
- Input and output
- File handling

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

bash
python expense_tracker.py
